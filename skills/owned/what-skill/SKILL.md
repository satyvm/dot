# Choose a skill

Read [the enabled skill catalog](references/catalog.md), generated by `ax skills sync`.
Recommend the most relevant skill and explain briefly how it fits the request.
Check its listed agent compatibility and dependencies before recommending it.

For installation status or a missing skill, run `ax skills list` or `ax skills doctor`.
The catalog covers the ax-managed library; also consider project skills and plugin
skills advertised in the current session. Do not assume a catalog entry makes
its required tools or MCP connections available.
